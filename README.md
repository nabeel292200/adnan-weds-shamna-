# adnan-weds-shamna-

Wedding Digital Invitation for Mohammad Adnan & Shamna built with Next.js 16 (App Router) and TypeScript.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- **Envelope Opening Gate Animation**: Video wax seal reveal experience.
- **Audio Controls**: Floating music toggle with animated equalizer bars.
- **Responsive Layout**: Designed for mobile and desktop screens.
- **Google Maps Integration**: Direct links and QR codes for Nikkah and Reception venues.
- **Interactive Reception Teaser**: Inline film reveal.
